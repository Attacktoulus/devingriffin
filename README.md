# devingriffin.com

Portfolio of Devin Griffin, Senior Graphic & Web Designer and Art Director. Static site: no build step.

## Structure

```
index.html                 homepage (hero film, about, services, tools, brands)
work/homes-by-avi/         case study 01 (teal)
work/cmca/                 case study 02 (green)
work/recent/               recent work (red)
info/                      experience and skills (night sky)
privacy/                   privacy policy
404.html                   not-found page
styles.css, main.js        shared styles and behaviour (nav, Work dropdown, menu, reveal, contact form)
work.css, work.js          case-study template, colour themes and gallery lightbox
shader.js                  WebGL background for the case studies
assets/                    images, hero film, CV, gallery images (assets/work/<page>/<gallery>/)
llms.txt                   plain-text profile for AI agents
robots.txt, sitemap.xml    search engine files
CNAME                      custom domain (do not delete)
info.html, work*.html      redirects from the old site's addresses
```

Gallery images and captions for each case study live in the `gallery-data` block near the bottom of that page's index.html.
Contact form submissions go to Formspree (form xqppngon).
